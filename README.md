## 🌟 Features Overview

- **🌐 Direct Web Input**: Inputs play actions directly into the web canvas without hijacking physical mouse devices.
- **🎥 Zero Camera Control**: Camera view stays 100% static so you can enjoy a smooth spectator view of your empire winning.
- **⏱️ Auto-Start on Game Begin**: Stays dormant in menus/lobbies and auto-activates the instant a game match begins.
- **🕒 Real-Time Progress Tracker**: Displays exact update timestamps on the HUD overlay and documentation.

## 🛠️ How to Install in Google Chrome

1. Open **Google Chrome** and go to `chrome://extensions/`.
2. Enable **Developer mode** (toggle in upper right corner).
3. Click **Load unpacked** (top left button).
4. Select folder: `/Users/phamvotriduc/Desktop/territorial-chrome-extension`
5. Open [https://territorial.io](https://territorial.io) and start a game!
